# 🦅 Acauã — Sistema de Gestão de Psicologia Individual

Sistema de gestão clínica 100% offline e seguro para psicólogos, projetado para garantir conformidade rigorosa com a LGPD e o Código de Ética do CFP.

## 🔒 Destaques de Segurança e Funcionalidades
- **Sigilo e Privacidade Absoluta:** Banco de dados SQLCipher AES-256 local com criptografia de ponta a ponta. Zero tráfego de dados sensíveis na nuvem.
- **Gestão de Pacientes & Prontuários:** Anamnese completa, evolução clínica e histórico de atendimentos.
- **Jornada Clínica (Kanban):** Organização visual dos estágios terapêuticos de cada paciente.
- **Agenda Inteligente:** Mapeamento de sessões, recorrências e status de presença.
- **Gestão Financeira:** Controle de receitas, despesas, recibos e fluxo financeiro do consultório.
- **Documentos & Atestados:** Geração de declarações, relatórios e atestados padronizados.
- **Bloco de Notas Rápido:** Anotações com persistência instantânea e confirmação segura.

## 🚀 Como Executar

```bash
# Instalar dependências
npm install

# Iniciar em modo de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
